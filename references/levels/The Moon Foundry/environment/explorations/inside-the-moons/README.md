# Inside the moons

The Moon Foundry, direction A. The unfinished moons are hollow, and people live inside them: on the inner curve of each shell, houses, stairs and gardens climb up the walls toward the top, lit through crater windows; the broken moon's courtyard is only the first. Gantries run from a crack in one moon to a hatch in the next, high under the roof.
