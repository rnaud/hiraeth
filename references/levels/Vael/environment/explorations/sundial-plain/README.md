# The plain is a sundial

Vael, direction C. The needles were not scattered: the riders set them, in rings round the lone tower, and the tower is the gnomon of a sundial as wide as the plain. Each needle is an hour; the riders' stones lie where its shadow falls; the rider promised to come back "when the tower's shadow touches the mounting stone", and the bird waits there.
