# The keepers' canopy

Lorn, direction B. The keepers did not live on the ground: their old village is up in the Deep Wood, at 60–120 m, in the trunks. Platforms ring the trunks, rope bridges run between them, little lamp-houses hang from the branches, and the Veils' great pale caps are the village's squares.
