# The drifting bridges

The City Floating in Space, direction B. A hand's width a night adds up: the bridges show it. Some are stretched and patched with planks, some have parted and hang in two halves, some are replaced by rope bridges, cable cars or a plank laid across; the islands have drifted to different heights so the bridges climb and drop. The moorers fight it with capstans on every island that reel the cables in.
