# The walking dunes

The Desert, direction B: great dunes walk in the wind, covering and uncovering ruins; sandfalls pour off the
mesas, sand rivers run between the dunes for the bike to ride, sand-sailors skim alongside. Prompts
`de-walking-dunes-establishing` and `de-walking-dunes-ground` in docs/design/level-explorations-prompts.md; the
author's picks land here.
