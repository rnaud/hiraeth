# The screen lanes

The Signal Market, direction A. Off the avenue, between the towers' feet, a warren of narrow lanes walled with second-hand screens, stacked to the first floors, each lit its own colour (the night references, built at eye level and lit by day too, under awnings). The menders work in them; every screen shows something different.
