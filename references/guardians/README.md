# The temple guardians' references

The reference lab's picks for the eleven temple guardians, one folder per guardian (`<id>/`: `sheet-N.jpg` and a
`manifest.json` the lab writes on Pick). The prompts are in `docs/design/guardian-prompts.md`: a design sheet (front,
side, three-quarter, its signature pose, its silhouette, the traveller for scale) and the guardian in its arena.
How the lab works: `docs/systems/reference-lab.md`.
