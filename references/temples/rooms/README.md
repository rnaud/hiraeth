# The temples' rooms

The reference lab's picks for rooms of the makers' temples beyond each temple's main hall and entrance (those are in
`../<temple>/`), one folder per room (`<temple>-<room>/`, e.g. `belfry-echoes/`: `sheet-N.jpg` and a `manifest.json`
the lab writes on Pick). The prompts are in `docs/design/temple-interior-prompts.md`; how the lab works:
`docs/systems/reference-lab.md`.
